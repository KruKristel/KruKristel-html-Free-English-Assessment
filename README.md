# Kru Kristel English Assessment Web App

A web-based English proficiency test designed for tutoring and student placement.

---

## 🌟 Features

- Grammar, Reading, Listening sections (auto-graded)
- Real-time scoring system
- Smart feedback based on performance
- Audio recording (student speaking test)
- Downloadable recording
- Student information capture (Name, Age, Level)
- LINE integration for easy booking
- Copy-to-message feature for student results
- Mobile-friendly interface

---

## 🧠 Assessment Structure

- Grammar & Vocabulary (15 questions)
- Reading (5 questions)
- Listening (10 questions)
- Total: 30 questions

---

## 📊 Results System

- Percentage breakdown per category:
  - Grammar & Vocabulary
  - Reading
  - Listening
- Overall performance feedback
- Personalized improvement suggestion

---

## 📲 Booking System

Students can:
- Copy their result message
- Contact teacher via LINE
- Send results directly for class booking
